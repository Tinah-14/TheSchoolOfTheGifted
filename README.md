# SCHOOL OF THE GIFTED – WEBSITE PROJECT

## 1. Project Overview

The School of the Gifted website is a web-based platform developed to provide learners, parents and prospective students with information about the school's educational services, academic programmes and contact details. The website aims to create an accessible, informative and user-friendly online presence that allows visitors to explore the school's services, learn about its educational approach and submit enquiries. The website is designed to support learners from Grade 1 to Grade 12, learners who wish to improve or supplement their Grade 12 results, and individuals interested in MICT skills.

## 2. Project Objectives

The main objectives of the website are to:

- Provide information about the School of the Gifted.
- Present the school's educational programmes and services.
- Allow visitors to submit enquiries.
- Provide contact information for prospective learners and parents.
- Create a professional and consistent online identity.
- Ensure the website is accessible across desktop, tablet and mobile devices.
- Improve communication between the school and its visitors.

## 3. Website Features and Pages

The website consists of the following pages:

| Contact Us | ContactUs.html | Provides contact information and a form for general communication. |
